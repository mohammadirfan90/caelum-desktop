# CR-023: DICOM C-STORE SCP (F-ACQ-06, network part)

- **Status:** proposed 2026-10-10. **Needs a product-owner decision.** It opens a network listener
  for medical images, so it is not approved under the standing delegation.
- **Affects:** `caelum-devices::files` (a new `dicom-ul` dependency), `caelum-core`, the signed
  `import` configuration.

## 1. Need
F-ACQ-06 lists DICOM import by file drop, folder watch and C-STORE SCP. File import and the
folder watch are built (CR-014, CR-022). The SCP lets an ultrasound unit send images over the
network.

## 2. Proposal
- **Dependency:** `dicom-ul` (part of dicom-rs, a stack item), pinned to the dicom-rs 0.10 line.
  It must be added to the offline tool cache: it is not in the cache today.
- **Listener:**
  - bound to one configured address on the medical-device LAN only;
  - accepts only the configured calling AE titles;
  - accepts only Storage SOP classes with the transfer syntaxes CR-014 §2 decodes.
- **Received objects:** go through the same path as the folder watch: they must open, are filed
  to the configured crew member, and are audited as the system.
- **Security:** DICOM Upper Layer has no authentication. It must run inside DICOM TLS (PS3.15
  Annex B, mutual certificates from the crew-LAN CA), or only on an isolated cable to the
  ultrasound unit.

## 3. Decision needed
Choose one:
- **(a)** DICOM TLS with mutual certificates;
- **(b)** plain DICOM on a dedicated isolated link, documented in the threat model;
- **(c)** keep file import and the folder watch only.

Until a decision is made, CAELUM has no network listener for DICOM.
