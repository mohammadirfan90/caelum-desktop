# CR-014: Clinical file formats (M8)

- **Status:** approved 2026-10-10 by engineering under the product owner's standing delegation.
  No new feature: format support and dependency decisions for F-ACQ-06, F-ACQ-07, F-ACQ-08 and
  F-SYS-08 (export).
- **Affects:** `caelum-devices::files` (pure parsing and writing on byte slices; file I/O and
  storage stay with the caller).

## 1. Principles
Each importer returns typed results with an explicit rejection reason. Nothing is defaulted or
invented (CLAUDE.md rule 2): a missing unit, time or calibration rejects the value. Originals
are kept by the caller in the encrypted attachment store (CR-019 §6).

## 2. DICOM (F-ACQ-06, F-ACQ-07)
- dicom-rs (a stack item) with no default features. Codecs are limited to pure Rust: JPEG
  (jpeg-decoder), RLE Lossless and Deflate.
- Data sets: Implicit VR Little Endian, Explicit VR Little and Big Endian, and Deflated
  Explicit VR Little Endian.
- Pixel data: native, Encapsulated Uncompressed, RLE Lossless, and JPEG Baseline, Extended and
  Lossless.
- JPEG 2000, JPEG-LS, JPEG XL, MPEG and HEVC need native or unsafe-heavy codecs and are not
  decoded. The object is still imported, and its pixel result says why it cannot be shown.
- Waveforms (12-lead ECG, PS3.3 C.10.9) are converted to physical units only when sensitivity,
  correction factor, baseline and unit are all present. µ-law and A-law samples are not decoded.
- The C-STORE SCP (network) and the folder watch are wired by the core. The SCP needs its own
  network CR before it is enabled.

## 3. ECG files (F-ACQ-07)
- **EDF / EDF+:** reader (physical scaling, annotations, continuous and discontinuous) and
  EDF+ writer. The writer round-trips within one 16-bit step.
- **HL7 aECG:** XML via quick-xml (a stack item); rhythm and representative-beat series.
- **SCP-ECG (EN 1064):**
  - Read: protocol 1.x and 2.x, sections 0, 1, 3 and 6 without Huffman encoding, with record
    and section CRCs verified.
  - Refused: Huffman coding, bimodal compression, reference-beat subtraction and version 3.0+.
  - Lead codes are named only where certain.

## 4. FHIR R4 import (F-ACQ-08)
- Observation, Device and DiagnosticReport, from a single resource or a Bundle. Each resource
  is imported or rejected on its own.
- Observations map to parameters only by the catalog's LOINC codes; unknown codes are reported,
  never guessed. LOINC 2708-6 (arterial O₂ saturation) is not the catalog's SpO₂ code and is
  not mapped to it.
- An Observation without a UCUM unit is rejected.

## 5. CSV export (F-SYS-08)
One file per parameter, RFC 4180 (CRLF, quoting), UTF-8 without BOM, UTC times with a flag when
the time lies beyond the leap-second table's expiry.
