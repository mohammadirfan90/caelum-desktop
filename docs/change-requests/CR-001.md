# CR-001: Onboard medical data system integration

- **Status:** approved (product owner), rev. 2 of the feature lock.
- **Change:** add F-GND-12 (two-way medical data system connector), F-GND-13 (dual routing),
  F-GND-14 (summary-first data policy); requirements R-INT-05..07; SR-015/016; hazards H-11/12.
- **Reason:** the crew health app feeds the onboard medical data system (MDA-class), which owns the
  health record and syncs to ground; critical alarms must not depend on it.
- **Safety impact:** reduces H-11 by keeping a direct operational path; adds H-12 (duplicates),
  controlled by SR-016.
- **Test impact:** new M10 gate scenarios (medical system unavailable during an emergency; two-way sync).
